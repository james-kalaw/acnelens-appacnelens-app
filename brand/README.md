# AcneLens brand

**Logo: "Clarity magnifier"** — a magnifying glass whose lens shows skin going from spotted (left) to clear (right):
look closely, get clearer skin. Colours: ink `#16363B`, coral `#E2725B`, sand `#F6EEE7`, blush `#F0C7B8`.
Wordmark: "acne" (Sora SemiBold) + "lens" (Sora Regular, coral).

| File | Use |
|---|---|
| `AcneLens-icon-1024.png` | App icon, slides, paper cover |
| `AcneLens-logo-light.png` | Logo + wordmark on white/light backgrounds (paper cover, documents) |
| `AcneLens-logo-on-dark.png` | Logo + wordmark on dark backgrounds (slides) |
| `svg/` | Scalable versions of everything (icons, mark only, wordmarks, lockups) |
| `src/make_logo.py` | Regenerates all SVGs: `python brand/src/make_logo.py <fonts_dir> brand/svg` |
| `concepts/` | Earlier rounds of logo concepts, for the record |
| `app-screens-preview.png` | Screenshots of the app |
