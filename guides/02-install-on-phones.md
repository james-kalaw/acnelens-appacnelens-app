# 2 · Install AcneLens on a phone

AcneLens is an **installable web app (PWA)**. Once installed it has its own home-screen icon, opens
full-screen like a normal app, and works **offline**. The first launch needs internet once (~35 MB:
the AI model and engine), so do this on Wi-Fi.

## Android (Chrome)
1. Open the app link in **Chrome**.
2. Tap **Install AcneLens on this phone** on the home screen of the app, **or** Chrome's **⋮** menu → **Install app** (older phones: **Add to Home screen**).
3. Tap **Install**. The AcneLens icon appears with your other apps.

## iPhone / iPad (Safari) — iOS 16.4 or newer
1. Open the app link in **Safari** (installing does not work from Chrome or Facebook's in-app browser on iPhone).
2. Tap the **Share** button (square with an up-arrow).
3. Scroll down and tap **Add to Home Screen** → **Add**.

## Optional: an Android .apk file
Not needed for normal use, but if the panel wants an installable file:
1. Go to **https://www.pwabuilder.com**, paste the app link, press **Start**.
2. Choose **Package for stores → Android → Generate package**, then download the zip.
3. Inside is an `.apk` you can install on Android (allow "install unknown apps" when asked).
iPhones cannot install apps from files; they use step "iPhone / iPad" above.

## Checklist before the consult
- [ ] Install on at least one Android and one iPhone.
- [ ] Turn on airplane mode and run one full check — it should still work.
- [ ] Bring a charger: the analysis runs on the phone itself.
